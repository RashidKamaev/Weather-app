# Weather App

Учебное Android-приложение для просмотра текущей погоды в выбранном городе.

Проект выполнен в рамках дополнительных занятий по мобильной разработке на **Kotlin**. В качестве задания был предоставлен готовый дизайн интерфейса, а моей задачей было самостоятельно реализовать приложение по макету и добавить весь необходимый функционал: получение данных из API, смену города, отображение погодных параметров и подбор иконок состояния погоды.

## Функциональность

Приложение позволяет:

- выбирать город из выпадающего списка;
- получать актуальные данные о погоде через **WeatherAPI**;
- автоматически обновлять данные после смены города;
- отображать текущую температуру;
- отображать текстовое описание погоды;
- менять иконку в зависимости от погодных условий;
- отображать локальное время выбранного города;
- отображать скорость ветра;
- отображать атмосферное давление;
- отображать влажность воздуха.

Сейчас доступны следующие города:

- Самара;
- Тольятти;
- Москва;
- Владивосток.

## Интерфейс

Основной экран состоит из трёх блоков:

1. выпадающий список для выбора города;
2. круглая карточка с иконкой погоды, описанием и температурой;
3. нижняя панель с дополнительными погодными параметрами.

Дизайн приложения был предоставлен как часть учебного задания. Реализация интерфейса и логики приложения выполнена на Kotlin с использованием Jetpack Compose.

## Работа с API

Для получения текущей погоды используется [WeatherAPI](https://www.weatherapi.com/).


В запрос передаются:

- API-ключ;
- выбранный город;
- язык ответа `ru`;
- отключённые данные о качестве воздуха (`aqi=no`).

Из ответа API используются следующие данные:

| Поле API | Назначение |
|---|---|
| `location.localtime` | локальное время выбранного города |
| `current.temp_c` | температура в °C |
| `current.condition.text` | описание текущей погоды |
| `current.condition.code` | код погодного состояния |
| `current.wind_kph` | скорость ветра |
| `current.pressure_mb` | атмосферное давление |
| `current.humidity` | влажность |

Перед выводом часть данных преобразуется:

- скорость ветра переводится из км/ч в м/с;
- давление переводится из mbar в мм рт. ст.;
- время приводится к формату `HH:mm`;
- температура округляется до целого числа.
